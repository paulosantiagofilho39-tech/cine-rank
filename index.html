CINE RANK

A nota CINE RANK é uma média ponderada das avaliações disponíveis em plataformas externas, convertidas para a escala 0–10. Cada nota mostra sua origem e data de atualização; quando uma fonte não está disponível, informamos. A Nota da Comunidade (avaliações feitas aqui) é calculada separadamente.

Este produto usa a API do TMDB, mas não é endossado nem certificado pelo TMDB. Notas do IMDb, Rotten Tomatoes e Metacritic, quando exibidas, vêm da API OMDb. Marcas e notas pertencem a seus respectivos titulares.

Configurações

As chaves ficam salvas só neste navegador (localStorage) e são usadas para consultar as APIs diretamente. Use apenas em uso pessoal/local; na versão com servidor (Next.js) as chaves ficam protegidas no backend.
